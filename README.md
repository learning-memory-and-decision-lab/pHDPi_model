# pHDP
Repository for "A normative account of human temporal structure learning." (2026)

This script was written on MATLAB 2023b and the required subfunctions are in "Funtions" folder. The pHDPi model is in HDP_July_2024.m file.
To run the pHDPi model, run the script: main_code_2024.m with the desired pararmeters for the task. ( task_type = 1 changepoint , task_type = 2 oddball, task_type = 3 reversal
and task_type = 4 sequence)
The output of this script is the model's predictions, as well as the inferred hyperparamters.
